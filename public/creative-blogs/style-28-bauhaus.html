// HAUPTTEXT 主叙事

一把椅子、一张海报与一个按钮的共同问题

当马歇·布劳耶在 1925 年把自行车把手的阿德勒无缝冷拔钢管弯成一把“瓦西里椅”时，他面临的技术抉择，与一名现代前端工程师在 CSS 中写下一个 <button> 的边框和内边距时别无二致。

包豪斯从来不是一种静态复古的装饰风格，而是一套解决工业化生产矛盾的认知协议。核心冲突始终在于：当制品从手工作坊的一对一独创，转变为数以万计的标准化复制时，材料的真实性、生产的经济性、操作的可用性与视觉的纯粹美感，该如何在同一种几何骨架中达成妥协？

无论是木材的纹理、钢管的曲率、纸张的铅字排版，还是当代屏幕上视口网格与触摸目标的像素尺寸，形式不应是外包的涂层，而是功能推演至终局时自然浮现的轮廓。

LEKTION 01 // FARBENLEHRE

红黄蓝并不是装饰捷径

大众常常将三原色误认为是包豪斯的一种波普化商标。但在伊顿与康定斯基的色彩研究中，红（直角的稳定与重力）、黄（锐角的尖锐与扩散）、蓝（圆形的向心与沉静）是信息层级的精确映射。如果色彩不能澄清功能优先级，它就是视觉噪音。
