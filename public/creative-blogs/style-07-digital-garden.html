🌲 常青笔记 (Evergreen) 📅 播种: 2025-11-14 • 🌱 最近浇灌: 2026-03-30 • 💬 反向引用: 4 篇

自治智能体协作协议：在网状知识与分布式行动之间

当独立的 LLM Agent 开始跨越单次 Prompt 的牢笼，它们所需要的不再是固化的 API 管道，而是一套容错、可回溯、具备明确权限阻尼的有机协议网络。

◈ 核心协议挂载节点（点击查看它连接了什么）

🛡️ 权限边界 Immutable

严格隔离 Agent 的读写上下文，所有持久化更改必须通过沙盒代理层，禁止跨域无签名操作。

📜 事件日志 Append-Only

记录每一次 Tool Call 的输入、输出与上下文衰减指纹，实现完全透明的决策因果链追踪。

⚡ 失败恢复 Gossip-Driven

当节点推理陷于幻觉循环时，触发梯度熔断，由监督节点提取上下文并进行三方投票重试。

👁️ 人工复核 HITL-Gate

在不可逆动作（如资金流转、删除持久索引）执行前，向管理员通道推送差异摘要与审批门禁。

在搭建跨智能体系统时，我们常常陷入一种机械论的执念——试图为每一种输入都穷举确定性的函数流。然而在真实生态中，多个智能体共处一个工作区，类似于花园中相互依存的菌丝网络。正如我们在 权限边界 中阐述的那样，自由度必须与沙盒的作用域严格对齐。

💡 思考碎片 (Garden Thought)： 文件夹强迫你在思考前就先决定分类；而双向链接允许你先记录灵感，等待模式自发涌现。智能体协议同样如此，先让它们在带约束的 事件日志 管道中自由通讯，再根据调用频率提取出正式契约。

一旦某一节点因为 Prompt 漂移或上下文过载进入非收敛状态，协议中的 失败恢复 机制会通过 Gossip 协议向相邻节点广播状态快照。若两次重试仍无法收敛至置信区间，便会优雅地降级至 人工复核 门禁，请求人类园丁的修剪介入。

🌿 培育中 • 关联: [[卡片盒笔记法]] [[渐进总结]]

《一条笔记如何长成文章》

一篇 3000 字的长文不该从空白页开始。它始于一行带问号的灵感（种子），在后续的阅读中被贴上三个反向链接（发芽），在与其它笔记的冲突中被反复重构提炼（抽枝），最后把五张相关的卡片串联并润色，文章便自然收获（常青）。
