# 《雨姐的心动时刻》v2.2 图片资源说明

## 📁 资源目录与引用规则

游戏图片资源统一部署在 `public/images/yujie/`。
前端代码与数据配置文件通过 `/images/` 前缀拼接数据路径进行加载（例如：数据中为 `yujie/cg_carry_pork_v2.png`，实际请求路径为 `/images/yujie/cg_carry_pork_v2.png`）。

本游戏图片资源仅用于粉丝二创小游戏（娱乐用途）。当引用的图片文件不存在或加载失败时，游戏引擎会自动使用配置的场景渐变色兜底，保证流程稳定不崩溃。

## 🛠️ 资产替换与维护指南

1. **CG 图片规范**：
   - 推荐采用 **16:9 比例**（如 1672×941 或 1920×1080），格式为 PNG 或高画质 JPG。
   - 画面构图需注意预留四周安全区，避免主体人物过于贴边。
2. **动作立绘规范**：
   - **必须为真透明 RGBA PNG**（Alpha 通道完整，无白色杂边/假透明网格）。
   - 保留角色全身完整轮廓与足底，由前端安全边距统一控制站位垂直对齐。
3. **配置文件与测试核验**：
   - 场景与角色定义：`src/data/yujieGameData.js`
   - 剧情与 CG 触发配置：`src/data/yujieGameEvents.js`
   - 每次修改或替换资源后，执行自动化测试校验：
     ```bash
     npm test
     ```
     测试套件会自动验证所有引用的图片物理存在性、CG 唯一映射以及各动作 pose 对应的立绘资源有效性。
