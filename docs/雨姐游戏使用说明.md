# 《雨姐的心动时刻》使用说明 🎮💕

## 🚀 快速开始

### 1. 启动开发服务器

在项目根目录运行：
```bash
npm run dev
```

### 2. 访问游戏

打开浏览器，访问：
```
http://localhost:5173/games
```

### 3. 开始游戏

1. 在游戏列表找到"雨姐的心动时刻"卡片
2. 点击卡片进入游戏封面
3. 若无在途存档，点击"开始这段缘分"开启新旅程；若有存档，可选择"继续上次旅程"或"重新开始"
4. 序章是线性的，跟着剧情走即可
5. 第 2 天起进入自由行动，想点哪里点哪里

## 🎯 游戏玩法（v2.1）

### 基本操作
- **推进剧情**：点击"点击继续"按钮，也支持使用键盘（Enter / 空格键）快速继续
- **点击选项**：做出选择，选项上方会飘字显示效果
- **自由行动地图**：每天 2 点行动点（⚡），去一个地点消耗 1 点；在小屏幕设备上地图支持内部滚动查看全部地点
- **回屋睡觉**：跳过当天剩余时间
- **保存并回标题**：随时点击顶部"💾 保存并回标题"，进度实时落盘并返回游戏主界面

### 状态说明
- **📅 天数**：共 13 天，第 13 天是抉择日
- **⚡ 行动点**：每天 2 点，用完自动入夜
- **❤️ 好感度**：雨姐对你的心意，感情结局的关键
- **👀 警觉度**：老蒯的提防，**涨到 45 直接触发"被赶走"结局**
- **💰 金钱**：厨房打工赚，集市购物花
- **🎒 物品栏**：展示当前持有道具，部分选项需要持有特定物品
- **📱 移动端 HUD**：手机端采用紧凑双行 HUD 设计，数值过多时支持横向滑动查看剩余状态与道具

### 六条支线（每个地点 3 幕剧情）
| 地点 | 关键词 |
|---|---|
| 🍳 大厨房 | 赚钱、厨艺、杀猪宴掌勺 |
| 🐷 猪圈 | 喂猪、起名、扛半扇猪名场面 |
| 🛒 村口大集 | 砍价、情报（雨姐喜好）、直播技巧 |
| 🌊 小河边 | 心动主线，好感大涨但警觉也涨 |
| 🥛 堂屋热炕 | 陪老蒯，大幅降低警觉 |
| ⛰️ 后山 | 采蘑菇/软枣/野花，大鹅老巢 |

### 固定日期事件
- **第 3 天**：村霸大鹅突袭
- **第 6 天**：赶集日（限定购物 + 神秘商人的"粉条"邀约……）
- **第 9 天**：雨姐的烦恼
- **第 12 天**：杀猪菜大宴（接了粉条单的话会变成大型翻车现场）

| 结局 | 达成条件 |
|---|---|
| 💕 心动结局 | 好感≥90、警觉≤40、走完河边线。秘诀：边追雨姐边哄老蒯 |
| 👨‍👩‍👦 东北一家人 | 走完堂屋线、警觉≤20 |
| 🧑‍🍳 金牌帮工 | 走完厨房线+猪圈线、好感≥60 |

| 🤝 好友结局 | 好感≥50，但没满足其他结局 |
| 😶 路人结局 | 一路睡大觉也能达成 |
| 🪿 大鹅之主（隐藏） | 跟大鹅互动 3 次以上 |
| 😡 被赶走 | 警觉≥45，老蒯忍无可忍 |

### 小贴士
- 开局 100 元，赶集日的军大衣（60 元）是心动主线神器
- 情报要先去大集找翠花买（5 元瓜子钱），河边送礼效果翻倍
- 只谈恋爱不理老蒯？警觉会教你做人
- 已解锁的结局会点亮开始界面的图鉴，集齐 9 个试试！

## 💾 存档与持久化机制（v2.1）

本版本支持完整的局内自动存档与持久化机制：

1. **自动存档**：关键推进、选项选择、每日行动切换均会自动存档。退出到游戏列表或刷新页面重进后，点击"继续上次旅程"即可无缝继续。
2. **重新开始**：若想重开，在标题界面点击"重新开始"会直接覆盖旧活动存档开启新一局。
3. **结局清理与图鉴保留**：达成任意结局后，当前局内进行中存档会自动清空结案，已解锁的结局图鉴保存在本地存储中（清空浏览器数据时会重置）。
4. **存储键名（浏览器 localStorage）**：
   - `yujie_save_v2`：记录当前局内进度（天数、阶段、数值、背包、支线步数等）
   - `yujie_gallery_v2`：记录已达成的 9 大结局图鉴列表
