# 《雨姐的心动时刻》使用说明 🎮💕

## 🚀 快速开始

### 1. 启动开发服务器

在项目根目录运行：
```bash
npm run dev
```

### 2. 访问游戏

打开浏览器，本地访问：
```
http://localhost:5173/games
```

### 3. 开始游戏

1. 在游戏列表找到“雨姐的心动时刻”卡片。
2. 点击卡片进入游戏封面。
3. 若无在途存档，点击“开始这段缘分”开启新旅程；若有存档，可选择“继续上次旅程”或“重新开始”。
4. 序章为线性剧情，顺着对话推进即可熟悉东北农家小院。
5. 第 2 天起正式进入自由行动地图（HUB），开启心愿指引与地点探索。

## 🎯 游戏玩法（v2.2）

### 基本操作
- **推进剧情**：点击“点击继续”按钮，也支持键盘（Enter / 空格键）快速推进。
- **点击选项**：做出选择后上方会飘字提示属性变动；若有明确未满足的前置条件，选项会展示提示锁定原因（隐藏剧情则保持神秘不剧透）。
- **自由行动地图（HUB）**：常规每天 2 点行动点（⚡），前往地点消耗 1 点；小屏设备下地图可滑动查看全部建筑。
- **回屋睡觉防误触**：
  - 行动点还有剩余时（⚡ > 0），点击睡觉会在卡片内二次确认“还剩 N 点体力”，支持取消或确认入夜；
  - 行动点耗尽时（⚡ = 0），点击直接入夜。
- **保存并回标题**：点击顶部“💾 保存并回标题”，当前进度实时写入本地存储并安全退回标题。

### 🌟 v2.2 全新“旅程心愿”与 HUB 导航
- **第 2 天初次进村选心愿**：第 2 天首次进入自由行动地图时，会在页面内直接挑选你的本局初衷（六大心愿之一）：
  1. **雨姐芳心**（主线心动浪漫路线）
  2. **东北一家人**（陪伴老蒯融入小院）
  3. **金牌帮工大厨**（掌勺大宴打工致富）
  4. **乡村带货新星**（规范经营电商助农）
  5. **全村大鹅之主**（村霸大鹅羁绊之路）
  6. **随性农家时光**（佛系看景顺其自然）
- **随时切换 & 不锁结局**：心愿仅提供当天的剧情推荐与进度提示，**绝不会锁死结局走向**。在 HUB 旅程指引下方展开可折叠的“旅途手记”即可自由修改心愿。
- **智能 HUB 信息流**：HUB 实时显示当前幕次、今日建议、下一个固定大事件倒计时与推荐前往路线。

### 状态与界面
- **📅 天数**：共 13 天，第 13 天为最终抉择日。
- **⚡ 行动点与特殊日程**：
  - 常规日期：每天 2 AP。
  - **第 3 天**：大鹅突袭固定事件为“免费”体验，剧情结束后当天依然享有完整的 2 AP！
  - **第 6 天 & 第 9 天**：上午大事件占用 1 AP，下午仍有 1 AP 可自由分配。
  - **第 12 天**：杀猪菜大宴整日为“特别日程”，专心体验高潮剧情，无需纠结普通 AP。
- **❤️ 好感度**：雨姐对你的信任与心动值，决定感情结局。
- **👀 警觉度**：老蒯对你的提防与危机感，**一旦涨到 45 会直接触发老蒯赶人结局**！
- **💰 金钱**：在大厨房打工赚钱，在集市购买关键道具。
- **🎒 物品栏**：展示当前持有道具。
- **📱 移动端自适应 HUD**：在 360px ~ 390px 紧凑手机屏幕下，天数、AP、好感、警觉、金钱五项核心数值一览无余，**无需横向滑动**；仅当物品栏道具较多时，道具区支持独立横滑查看。
- **🖼️ 视觉表现升级**：CG 支持全屏沉浸展示，角色动作立绘更加生动饱满。

### 💡 游玩小贴士
1. **启动资金与送礼**：开局拥有 100 元，第 6 天赶集日的军大衣（60 元）是推进河边心动主线的强力道具。
2. **情报打听**：先去大集花 5 元向翠花打听雨姐喜好，河边送礼可获得翻倍心动反馈。
3. **平衡警觉**：只顾小河边约会会导致老蒯警觉飙升，常回堂屋陪老蒯喝 AD 钙奶唠嗑是通关保障。
4. **图鉴收集**：通关任意结局后会自动点亮封面的结局图鉴，欢迎挑战全 9 结局收集！

## 💾 存档与持久化机制（v2.2）

1. **实时自动存档**：对话推进、分支抉择、行动点消耗及切换天数时均会自动落盘。即使刷新页面或退回游戏列表，点击“继续上次旅程”即可无缝接关。
2. **新开游戏**：点击标题界面的“重新开始”会覆盖当前活动进度重新开局。
3. **结案与图鉴保存**：触发结局后，当局进度会自动归档清空，已解锁的结局图鉴保存在浏览器本地存储（localStorage）中；注意清除浏览器站点数据会导致图鉴重置。
4. **本地存储键说明**：
   - `yujie_save_v2`：当局游戏存档（包含天数、数值、背包、支线步数与心愿 wishId，兼容 v2 旧存档）。
   - `yujie_gallery_v2`：9 大结局全图鉴解锁记录（本地持久保存）。
