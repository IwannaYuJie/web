# 《雨姐的心动时刻》独立分发页实现文档

## 1. 页面定位与访问地址

本项目为《雨姐的心动时刻》制作了独立的对外传播与分发页面（Landing Page），提供纯净、无剧透的游戏内容概览、氛围传达与即开即玩入口，便于在外部社交平台、即时通讯工具中分享。

* **正式线上入口**：`https://jumaomaomaoju.cn/yujie/`
* **本地开发入口**：`http://localhost:5173/yujie/`
* **游戏本体入口**：`/games/yujie`
* **当前状态**：`本地实现待发布验证`（未完成线上验证前不得标记为已上线）

---

## 2. 架构方案：Vite 多入口（MPA）静态产物

生产环境采用 Caddy 直接托管 `dist/` 静态目录。为确保分发页拥有干净独立的 URL、专属 OpenGraph 元数据与独立的 HTML 入口，同时避免单页应用内部路由跳转的初始化开销，采用 Vite 多入口（Multi-Page App）构建方案：

1. **入口配置**：在 `vite.config.js` 的 `rollupOptions.input` 中同时配置主站 `index.html` 与分发页 `yujie/index.html`。
2. **构建产物**：执行 `npm run build` 后，在 `dist/yujie/index.html` 生成独立 HTML 文件。
3. **服务响应**：用户访问 `https://jumaomaomaoju.cn/yujie/` 时，Caddy 静态服务直接命中 `dist/yujie/index.html`，天然支持 Canonical URL 与社交平台爬虫抓取。

## 4. 分享与剪贴板降级机制

页面提供健壮的分享与链接复制逻辑，兼顾移动端系统原生面板与桌面端剪贴板：

1. **Web Share API 优先**：若浏览器支持 `navigator.share`，调用系统原生分享面板，传递页面标题、描述及 Canonical URL。
2. **Clipboard API 次之**：若不支持原生分享或用户在桌面端点击，使用 `navigator.clipboard.writeText` 写入分发页链接，并在界面展示轻量提示状态。
3. **Textarea DOM Fallback 保底**：在旧版移动端或未授权剪贴板的 WebView 环境中，创建不可见 `textarea` 执行 `document.execCommand('copy')` 完成兜底复制。

## 6. 工程文件清单（共 7 个文件）

1. `vite.config.js`：配置 Rollup 多入口，注册 `yujie/index.html`。
2. `yujie/index.html`：独立 HTML 模板，包含专用 title、meta 标签与 canonical 链接。
3. `src/yujie-main.jsx`：分发页 React 挂载入口。
4. `src/pages/YujieSharePage.jsx`：分发页主结构组件与交互逻辑。
5. `src/pages/YujieSharePage.css`：分发页样式表，响应式排版与色彩定义。
6. `test/yujieSharePage.test.js`：Node.js 静态契约测试脚本（校验 HTML 元数据、MPA 隔离、分享代码、资产唯一性与引用路径）。
7. `docs/雨姐游戏分发页.md`：本技术与交付说明文档。
