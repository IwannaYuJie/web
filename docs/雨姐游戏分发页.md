  - `你与她并肩，关系会走向另一种默契。`
- **老蒯说明**：明确交代老蒯在不同路线中的特殊角色与互动逻辑。
- **剧照画廊**：4 张游戏内剧照各出现一次。
- **底部行动区**：「开始这段缘分」与「复制分发链接」双按钮。
- **Footer**：仅保留「橘猫小窝 · 网页端即开即玩」及返回博客链接。

## 4. 分享链路与降级逻辑
1. 优先调用 `navigator.share` 调用系统原生分享。
2. 原生分享失败或环境不支持时，降级使用 `navigator.clipboard.writeText` 写入分发链接。
3. 剪贴板 API 仍不可用时，降级为动态创建隐藏 `textarea` 并调用 `document.execCommand('copy')`。
4. 用户主动取消原生分享时做静默处理，不触发错误提示。
