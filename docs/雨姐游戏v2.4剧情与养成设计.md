# 《雨姐的心动时刻》v2.4 剧情与养成系统终审设计规范

---

## 1. 体验目标与系统原则

### 1.1 核心体验定位
《雨姐的心动时刻》（v2.4）是一款以东北乡村农家乐为舞台的叙事经营与情感羁绊文字单页游戏（SPA）。玩家扮演来到农家乐的青年“杰克”，在为期 13 天的日常劳作与生活相处中，与性格豪爽大气的**雨姐**、沉默务实内敛的**老蒯**、热心邻里**佩斯**与**翠花**、以及特立独行的**村霸大鹅**展开多元羁绊。

### 1.2 核心设计原则
1. **去显式功利化（隐去数值迷雾）**：
   - 选项按钮文案严禁标明 `[雨姐好感+5]`、`[老蒯警惕+10]`、`[正确选项]` 或 `[危险]` 等数值剧透标签。
   - 选项文案必须基于情境、人物动机、价值观与行动方式，玩家通过语气和常识推理后果。
   - 一周目 HUD 仅显示抽象关系阶段词（如“萍水相逢”、“默契搭档”、“知心挚友”）；二周目手记才解锁精确数值结算与差分提示。
2. **选择具备真实代价与多样反馈**：
   - 全局至少 30% 的有意义选择伴随负面效果、代价与收益并存、或引入风险/互斥 flag（如贪图便宜省钱导致品质隐患、过度越界招致警惕、两头许诺埋下信任危机）。
   - 不设一眼看穿的“小丑选项”，所有选项均符合特定立场或诱因。
3. **真实 18 AP 动态节奏**：
   - 严格遵循真实行动力预算：全流程 13 天，总自由行动点（AP）精确为 **18 AP**。晨间剧情不占 AP，主线固定事件消耗 1 AP 并留 1 AP，D12 盛宴全天专场无自由 AP，D13 终章汇总无自由 AP。
   - 杜绝无意义刷分：老蒯、猪圈、集市、河边等路线达到最高幕数后关闭；唯有厨房保留 `route_kitchen_repeat`（做家常菜）可作为通用补足手段。
4. **承诺排他与性格塑造机制**：
   - 雨姐展现三种人格态（柔软依恋、平衡搭档、强势主导），由杰克在 D5/D8/D10/D12 回响中的担当与处事风格决定。
   - 老蒯路线支持“兄弟知己”与“浪漫双向确认”两条健康路线，严谨界定清醒状态下的知情同意；若玩家在两人之间同时作出排他承诺，将在 D12 触发不可逆的修罗场结局。
5. **系统完整闭环与向前兼容**：
   - 精确保留既有 42 个事件 ID 并更新内部内容，新增精确 20 个事件 ID，事件总数精确为 **62 个**。
   - 精确保留既有 9 个结局 ID，新增 5 个结局 ID，总结局数精确为 **14 个**。
   - 严格保持现有 `yujie_save_v2` 存储键，通过 `migrateStats(oldStats)` 安全补齐缺省字段，确保旧版存档无损升级。

### 2.3 UI 展示策略与迷雾机制
- **一周目玩家 HUD**：
  - 雨姐关系：展示模糊称号（`affection < 30`“客套东家”；`30..69`“合拍帮手”；`70..99`“知心密友”；`>= 100`“生死搭档”）。
  - 老蒯关系：展示模糊称号（`laokuaiAlert >= 30`“冷眼警惕”；`laokuaiBond >= 40`“过命兄弟”；`laokuaiRomance >= 40`“暗生默契”；其他“低头木工”）。
  - 资金：实时显示 `money`。
  - 行动力：实时显示今日剩余 AP 槽（如 `[●][○]`）。
- **二周目玩家手记（回顾系统）**：
  - 完整解锁精确数值面板、雨姐 Softness 倾向槽（-40..40）、老蒯警戒红线进度（/45）以及历史选择的实际增减数值提示。

## 3. 选项设计规范与 12 组示范场景

### 3.1 选项迷雾与自然平衡原则
1. **行文自然**：选项文本必须是角色会说的话或具体的处事策略，禁止写“【加好感】”、“【调查】”。
2. **代价可见但非全知**：玩家可从生活常理推断风险（如省钱可能货不对板，越界追问可能招人反感，大包大揽可能加重对方压力）。
3. **即时叙事反馈（Feedback）**：点击后立即通过 1~2 句文本生动展现角色的眼神、微表情或动作反应。

### 3.2 12 组典型选择与后果示范

#### 示例 1：D2 厨房初遇（`route_kitchen_1`）
- **情境**：雨姐正在大锅前奋力翻炒几十斤大烩菜，热气熏天，满头大汗。
- **选项 A**：`“姐，你歇口气，这锅铲重，剩下的我来翻！”`
  - *真实后果*：`affection +4, yujieSoftness +5, integrity +2`
  - *Feedback*：雨姐先是一愣，随即爽朗大笑把铲子递给你，眼底掠过一丝被照顾的欣慰。
- **选项 B**：`“雨姐真是一把好手！我在旁边给你递调料、打下手。”`
  - *真实后果*：`affection +3, yujieSoftness -3, money +10`
  - *Feedback*：雨姐手起勺落，动作行云流水，赞许你眼力见好，顺手塞给你刚出锅的肉块。
- **选项 C**：`“做这么大锅容易受热不均，是不是火候有点猛了？”`
  - *真实后果*：`affection -2, integrity +3`
  - *Feedback*：雨姐斜眼瞅了你一下：“大锅菜就得靠这股子柴火烈气！城里娃懂个啥。”

#### 示例 2：D3 猪圈起早（`route_pigpen_1`）
- **情境**：后院猪食槽边，老蒯正默默扛着沉重的泔水桶，脚步有些踉跄。
- **选项 A**：`快步上前接过重担：“蒯哥，咱俩一人一边抬，别伤了腰。”`
  - *真实后果*：`laokuaiBond +6, laokuaiAlert -4, integrity +3`
  - *Feedback*：老蒯肩膀一松，没有多言，只是默默递给你一只防滑手套。
- **选项 B**：`站在干燥处提醒：“蒯哥，地面太滑，你慢点走别摔了。”`
  - *真实后果*：`laokuaiBond +1, laokuaiAlert +2`
  - *Feedback*：老蒯闷哼一声，自顾自把桶倒进槽里，没抬头看你。
- **选项 C**：`掏出手机记录：“这东北笨猪个头真壮，拍个视频发网上肯定火！”`
  - *真实后果*：`laokuaiAlert +8, laokuaiBond -3, setFlags: { liveSkill: true }`
  - *Feedback*：老蒯眉头紧锁，身子侧过去挡住镜头，脸色沉了下来。

#### 示例 3：D4 集市物价（`route_market_2`）
- **情境**：集市摊位上，商贩要价虚高，正极力推销品质一般的干货。
- **选项 A**：`“大叔，这花菇成色杂了，乡里乡亲的，给个实诚底价。”`
  - *真实后果*：`money -30, integrity +4, affection +3`
  - *Feedback*：摊主见你是懂行的，讪讪地抹了零头，换了一包上等货。
- **选项 B**：`“太贵了，雨姐农家乐要大量进货，不打七折我们去别家。”`
  - *真实后果*：`money -20, integrity -2, laokuaiAlert +3`
  - *Feedback*：摊主有些不悦地成交，旁边围观的乡邻低声议论你有些仗势压人。
- **选项 C**：`直接全额买下：“出门在外都不容易，不用找了。”`
  - *真实后果*：`money -50, affection +2, yujieSoftness -4`
  - *Feedback*：买是买痛快了，雨姐得知后敲了你脑门一下：“真是个不会过日子的冤大头！”

#### 示例 4：D6 粉条危机决断（`ev_noodle_man`）
- **情境**：神秘小贩运来一批极便宜的“东北大拉皮粉条”，但包装简陋，产地模糊，而盛宴缺口迫在眉睫。
- **选项 A**：`“价格确实极低，先订这批顶上盛宴的缺口，能省一大笔开支。”`
  - *真实后果*：`money -20, integrity -15, setFlags: { noodleCheap: true, noodleDeal: true }`

- **选项 B**：`“当场拆一包用开水试煮，闻闻有没有胶味，留样验过再定。”`
  - *真实后果*：`money -10, integrity +8, setFlags: { refusedNoodles: true }`
  - *Feedback*：热水一浇，粉条散发出一股刺鼻异味，小贩见状慌忙收摊溜走。
- **选项 C**：`“宁可多花钱跑正规老作坊现拉现采，绝不能砸了大院的招牌。”`
  - *真实后果*：`money -50, integrity +12, affection +6, setFlags: { refusedNoodles: true }`
  - *Feedback*：多跑了三十里路买回纯正土豆粉，雨姐得知后拍着你肩膀赞许你的硬气。

- **情境**：昏暗的木工棚里，老蒯递给你一杯烈酒，聊起当年与雨姐创业的辛酸与自己的力不从心。

#### 示例 6：老蒯第 4 幕 温酒坦白边界（`route_laokuai_4`，需 D7+）

### 10.2 路线最大幕数支持
在引擎中引入 `getRouteMaxStage(routeId)`，优先读取 `routes[routeId].maxStage`，老蒯默认回退 5，其余路线默认回退 `MAX_ROUTE_STAGE || 3`；厨房路线是否可重复由该路线配置的 `repeatable` 及 `routeEventId` 决定：
```javascript
export const getRouteMaxStage = (routeId) => {
  if (routes && routes[routeId] && typeof routes[routeId].maxStage === 'number') {
    return routes[routeId].maxStage
  }
  if (routeId === 'laokuai') {
    return 5
  }
  return MAX_ROUTE_STAGE || 3
}
```

### 10.3 存档迁移纯函数行为契约（`migrateStats`）
存档升级函数 `migrateStats(oldStats)` 遵循以下迁移与安全校验规范：
1. **输入防御与默认基准**：接收任意 `oldStats` 输入。若输入非对象或为 `null` 则视为空对象 `{}`，所有缺省字段严格以 `initialStats()` 产生的基础结构为基准回退。
2. **数值与数字字符串解析与 Clamp**：对所有数值字段统一通过解析逻辑处理（支持有限数值与非空数字字符串，非法或缺省时回退 `init` 对应默认值），并严格约束在真实业务区间内：
   - `affection`: `[0, 120]`
   - `yujieSoftness`: `[-40, 40]`
   - `laokuaiBond`: `[0, 100]`
   - `laokuaiRomance`: `[0, 100]`
   - `laokuaiAlert`: `[0, 100]`
   - `integrity`: `[-30, 30]`
   - `money`: `[0, 9999]`
   - `day`: `[1, 13]`
   - `actionPoints`: `[0, 2]`
   - `gooseCount`: `[0, 10]`
3. **六大路线进度迁移**：读取 `source.routes` 对象，对 `kitchen`、`pigpen`、`market`、`riverside`、`laokuai`、`mountain` 六个路线字段分别按 `0` 到 `getRouteMaxStage(routeKey)` 进行数值解析与区间限制，缺省时回退 `init.routes` 对应初始值。
4. **复合引用安全拷贝**：
   - `items`：若 `source.items` 为数组则进行浅拷贝 `[...source.items]`，否则回退 `[...init.items]`。
   - `flags`：若 `typeof source.flags === 'object' 且 source.flags !== null` 则浅拷贝 `{ ...source.flags }`；否则回退 `{ ...init.flags }`（即 `{}`）。
   - `historyLog`：若 `source.historyLog` 为数组则通过 `JSON.parse(JSON.stringify(source.historyLog))` 完成深拷贝，防止引用污染；否则回退 `[...init.historyLog]`。
5. **完整 14 个顶层字段契约**：迁移产物为一个干净的独立状态对象，精确包含以下 14 个顶层字段，且绝不包含不存在的字段（如 `currentScene` 等）：
