# 《雨姐的心动时刻》重制版 · 游戏开发文档 💕

## 📖 游戏简介

《雨姐的心动时刻》v2.2 是一款以东北网红雨姐为原型的恋爱模拟 + 玩梗收集游戏（Galgame）。玩家扮演来到东北农家乐的外国小伙杰克，在 **13 天**旅程中分配行动点（AP）、探索六条支线、经历序章与四个正篇阶段的剧情变迁，最终触发九个结局之一。

v2.2 版本重构了日程与调度模型，引入序章与四个正篇阶段的剧情推进结构与心愿导航指引，新增 6 张 16:9 剧情 CG 与 7 张透明动作立绘，并完成了对话框高度自适应、立绘站位分层与移动端交互体验升级。

## 🎮 游戏结构与阶段节奏

游戏全长 13 天，划分为序章 + 四个正篇阶段（`acts` 共 5 段）：

```
第1天：序章（初来乍到，结识大院众人，线性教学）
  ↓
第2-5天：融入大院（熟悉农家日常，与雨姐和伙伴建立初步羁绊）
  ↓ （第3天早晨：大鹅突袭固定事件）
第6-8天：选择方向（赶集风波与考验，明确心愿奔赴方向）
  ↓ （第6天早晨：村口大集固定事件）
第9-11天：最后冲刺（大宴筹备，冲刺核心好感、技能与前置条件）
  ↓ （第9天早晨：雨姐的烦恼固定事件）
第12-13天：盛宴与告别（全村盛宴与最终抉择，落幕）
  ↓ （第12天特别日程：杀猪菜大宴 / 翻车曝光；第13天：离别抉择）
```

### 核心数值

| 数值 | 说明 |
|---|---|
| ❤️ 好感度 (`affection`) | 雨姐对杰克的心意，决定感情类结局 |
| 👀 警觉度 (`laokuaiAlert`) | 老蒯的提防，**≥45 任意时刻强制触发「被赶走」结局** |
| 💰 金钱 (`money`) | 初始 100 元，大厨房打工赚取，村口大集购物消费 |
| 🎒 物品 (`items`) | 送礼或解锁特殊选项（AD钙奶、软枣、酸菜、野花、半扇猪肉、榛蘑、军大衣、大鹅蛋共 8 种） |
| 🪿 鹅王之证 (`gooseCount`) | 与大鹅互动/单挑/摸蛋次数，≥3 解锁隐藏结局 |
| ⚡ 行动点 (`actionPoints`) | 常规自由行动每天 2 点 AP，进入支线地点消耗 1 点 |

## 🧭 心愿导航机制（Wish Guides）

为了提升自由行动阶段的目标感，v2.2 引入了 **6 种可随时切换的心愿指引**（数据定义在 `wishGuides`）：

| 心愿 ID | 目标结局 | 核心推荐路线 | 追踪指标 |
|---|---|---|---|
| `love` | 心动结局 (`ending_love`) | 小河边、堂屋热炕、后山 | 雨姐好感 (≥90)、老蒯警觉 (≤40)、小河边支线 (3幕) |
| `family` | 东北一家人 (`ending_family`) | 堂屋热炕、村口大集 | 堂屋支线 (3幕)、老蒯警觉 (≤20) |
| `chef` | 金牌帮工 (`ending_chef`) | 大厨房、猪圈 | 厨房支线 (3幕)、猪圈支线 (3幕)、雨姐好感 (≥60) |
| `streamer` | 带货新星 (`ending_streamer`) | 村口大集 | 大集支线 (3幕)、选择直播路线、拒绝贴牌粉条 |
| `goose` | 大鹅之主 (`ending_goose`) | 后山、猪圈 | 大鹅互动次数 (≥3) |
| `casual` | 随性农家时光 (`ending_friend`) | 无特定路线推荐 | 纯净体验农家乐，无强制指标 |

**心愿指引设计原则**：
- **纯粹引导，不绑判定**：心愿仅用于在 HUB 界面展示进度清单、高亮推荐路线与下一步建议，**完全不参与**最终结局分支的硬性计算。
- **随时切换与容错**：玩家在自由行动 HUB 可随时切换心愿；存档顶层增加可选字段 `wishId`（缺失或非法值自动回退为 `null`，兼容旧存档）。

## 📅 日程调度与 AP 语义

v2.2 修正了对自由行动的过度简化，明确了固定日程与行动点的结算语义：

1. **第 3 天早晨（大鹅突袭 `ev_goose_attack`）**：
   - 属于**免费固定事件**；
   - 事件完成后返回 HUB，玩家依然拥有整天完整的 **2 AP** 自由行动。
2. **第 6 天早晨（赶集日 `ev_market_day` → `ev_noodle_man`）**：
   - 晨间赶集与商人推销，做出关键选择后消耗 1 AP；
   - 回到 HUB 留有 **1 AP** 供下午自由行动。
3. **第 9 天早晨（雨姐的烦恼 `ev_yujie_trouble`）**：
   - 为雨姐出谋划策，消耗 1 AP；
   - 回到 HUB 留有 **1 AP** 供下午自由行动。
4. **第 12 天（特别日程 `specialSchedule`：`ev_feast` 或 `ev_expose`）**：
   - 全村盛宴或翻车曝光属于全天主线事件，标记为 `specialSchedule: true`；
   - HUB 与 HUD 不显示具有误导性的普通 AP 计数。
5. **第 13 天（抉择日 `ev_final`）**：
   - 离别终章，直接根据当前数值与剧情开关激活结局分支。

### 3. 舞台与立绘渲染规则（`pose` 与 `expression` 分离）
- **选图优先级**：`pickStageSprite(char, seed, pose, expression)` 优先匹配动作 `pose`，次级匹配表情 `expression`，最后通过 djb2 种子哈希 `hashSeed` 稳定轮换回退。
- **CG 与立绘避让**：纯函数 `shouldRenderStage(event)` 确保当事件配置了 `cg` 或 `hideStageSprites: true` 时，**不渲染前景人物立绘**，避免双重人物画面重叠穿帮。
- **双层 Contain 背景呈现**：CG 大图使用主图完整展示（`object-fit: contain`）结合底层高斯模糊垫底（`blur backdrop`），在移动端与桌面宽屏均保证构图完整不裁切。
- **对话框高度测量与立绘站位**：通过 `ResizeObserver` 动态测量对话框真实高度，写入 CSS 变量 `--dialogue-height`，立绘底部始终对齐对话框上方安全区；移动端屏幕下旁白最多展示 2 位角色，对白仅保留当前说话者。

## 💻 数据模型与纯逻辑引擎

### 事件模型配置示例

当前游戏共包含 **36 个事件节点、59 条对白数据、83 个分支选项**。

```javascript
{
  id: 'route_riverside_2',
  title: '心意',
  scene: 'riverside',                          // 场景背景 id
  cg: null,                                    // CG 资产路径，非空时覆盖背景并隐藏前景立绘
  hideStageSprites: false,                     // 可选，强制隐藏立绘
  specialSchedule: false,                      // 是否为全天特别日程（不展示普通 AP）
  dialogue: [
    {
      character: 'yujie',
      pose: 'carrying',                        // 优先指定动作姿态立绘
      expression: 'gentle',                    // 表情（用于头像与立绘回退）
      text: '大兄弟，歇会儿，跟姐唠唠心里话。'
    }
  ],
  choices: [
    {
      id: 'riv_2_1',
      text: '献上手里采的野花',
      condition: { hasItem: 'flower' },        // 选项条件
      lockedHint: '需要背包中有「野花」',       // 锁定提示；若无此字段且不满足条件则直接隐藏
      effects: {
        affection: 15,
        laokuaiAlert: 12,
        removeItem: 'flower'
      },
      advanceRoute: 'riverside',               // 推进支线进度
      next: 'HUB'                              // 下一跳转：HUB / NIGHT / 事件ID / 结局ID
    }
  ]
}
```

### 选项锁定提示逻辑
- 若选项设置了 `condition` 且未满足：
  - 配置了 `lockedHint` 时：显示为 `disabled` 状态，并附带置灰提示文字，让玩家明确获取条件；
  - 未配置 `lockedHint` 时：该选项继续保持安全隐藏。

### 纯逻辑引擎接口清单（`yujieGameEngine.js`）

| 函数 | 职责 |
|---|---|
| `initialStats()` | 生成初始玩家状态 |
| `applyEffects(stats, choice)` | 不可变结算选项数值、物品、AP、标志与支线进度 |
| `checkCondition(condition, stats)` | 评估选项前置条件（好感/警觉/金钱/物品/flag/鹅王之证/支线幕数） |
| `summarizeChoice(choice)` | 生成选项反馈飘字提示数组（Toast） |
| `morningEventForDay(day, flags)` | 判定当天清晨是否强制触发固定日期事件 |
| `routeEventId(routeId, stage)` | 依据支线进度计算对应事件 ID |
| `getActForDay(day)` | 依据天数获取所属的剧情阶段对象 |
| `getNextScheduledEvent(day)` | 获取晚于当前天的下一个固定日程及倒计时 |
| `getWishProgress(wishId, stats)` | 评估当前心愿各项指标的达成度（已完成/目标值） |
| `getRecommendedRoutes(wishId)` | 获取当前心愿推荐前往的地点 ID 列表 |
| `shouldRenderStage(event)` | 纯逻辑判定是否需要渲染舞台全身立绘 |
| `pickStageSprite(char, seed, pose, expression)` | 舞台立绘按动作/表情/种子层级选图 |
| `pickPortrait(char, seed, expression, kind)` | 头像与立绘哈希保底选图 |

## 💾 存档、图鉴与 HUB 交互

### 1. 存档与存储规范
- **活跃存档键**：`yujie_save_v2`（保存在 `localStorage`）。
- **图鉴收集键**：`yujie_gallery_v2`（记录已解锁结局 ID 数组，支持开始界面 `x/9` 展示）。
- **存档结构**：
  ```javascript
  {
    stats: {
      day: 1,
      actionPoints: 0,
      affection: 0,
      laokuaiAlert: 0,
      money: 100,
      items: [],
      routes: { kitchen: 0, pigpen: 0, market: 0, riverside: 0, laokuai: 0, mountain: 0 },
      flags: {},
      gooseCount: 0
    },
    mode: 'event',                  // 'event' | 'hub'
    currentEventId: 'pro_meet_jack',
    dialogueIndex: 0,
    wishId: null,                   // 当前选中心愿（可选字符串，缺失或非法安全回退 null）
    timestamp: 1711234567890
  }
  ```
- **存档生命周期**：
  - 进入结局或玩家主动在开始界面点击「重新开始」时清理活跃存档；
  - 遇到非法/损坏数据安全忽略，不引起页面崩溃；
  - 组件实现对话进度实时与主动存储，支持通过顶部「💾 保存并回标题」返回标题。

### 2. HUB 交互功能
- **旅程指引面板**：顶部清晰展示当前所处的剧情阶段、下一固定事件与倒计时天数。
- **心愿切换与进度清单**：折叠面板中可自由切换 6 种心愿，实时查看好感、警觉、支线达成度进度条。
- **推荐路线标识**：地图卡片根据当前心愿高亮推荐前往的地点。
- **防误触睡觉确认**：当剩余 `AP > 0` 时，点击「结束今天/入夜」将在原卡片内弹出原地确认提示，防止误跳过行动点。
- **可折叠旅途手记**：展示当前心愿达成条件与六大支线进度概览（背包道具由顶部独立物品栏实时展示）。
