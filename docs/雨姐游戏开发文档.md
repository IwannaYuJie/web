# 《雨姐的心动时刻》重制版 · 游戏开发文档 💕

## 📖 游戏简介

《雨姐的心动时刻》v2.0 是一款以东北网红雨姐为原型的恋爱模拟 + 玩梗收集游戏（Galgame）。玩家扮演来到东北农家乐的外国小伙杰克，在 **13 天**里自由分配每天 2 点行动点，推进六条支线，触发九个结局中的一个。

## 🎮 游戏结构

```
序章（第1天，线性教学）
  ↓
自由行动（第2-12天，每天2行动点，自选地点推进支线）
  ↓ 其中第3/6/9/12天早晨强制插入日期事件
终章（第13天，抉择日 → 结局判定）
```

### 核心数值

| 数值 | 说明 |
|---|---|
| ❤️ 好感度 | 雨姐对杰克的心意，决定感情类结局 |
| 👀 警觉度 | 老蒯的提防，**≥45 强制触发「被赶走」结局** |
| 💰 金钱 | 初始 100 元，厨房打工赚，集市购物花 |
| 🎒 物品 | 送礼/解锁特殊选项（AD钙奶、软枣、野花、军大衣等 8 种） |
| 🪿 鹅王之证 | 与大鹅互动次数，≥3 解锁隐藏结局 |
| ⚡ 行动点 | 每天 2 点，去一个地点消耗 1 点 |

### 六条支线（每条 3 幕）

| 地点 | 内容 | 主要收益 |
|---|---|---|
| 🍳 大厨房 | 帮厨→切酸菜→掌勺（走完后可反复打工 +15元） | 金钱+好感，杀猪宴加成 |
| 🐷 猪圈 | 喂猪→起名→扛半扇猪 | 大量好感 + 半扇猪肉 |
| 🛒 村口大集 | 砍价→情报（雨姐喜好）→直播技巧 | 情报/直播线前置 |
| 🌊 小河边 | 谈心→送礼→心动时刻（好感主线，警觉飙升） | 心动结局核心 |
| 🥛 堂屋热炕 | AD钙奶外交→男人谈心→结拜 | 警觉大降 |
| ⛰️ 后山 | 采蘑菇→摘软枣→大鹅老巢 | 采集物品/鹅王之证 |

### 固定日期事件

- **第3天 大鹅突袭**：单挑/逃跑/呼救三种应对
- **第6天 赶集日**：限定购物（军大衣60/AD钙奶25/软枣20）+ 神秘商人推销贴牌"木薯粉条"（彩蛋分支点）
- **第9天 雨姐的烦恼**：干活/直播（需先学直播技巧）/陪伴
- **第12天 杀猪菜大宴**：按支线完成度解锁掌勺/扛猪高光选项；若接了粉条单则强制进入翻车剧情
- **第13天 抉择日**：结局选项按条件亮起

### 九个结局

| 结局 | 条件 |
|---|---|
| 💕 心动 | 好感≥90，警觉≤40，走完河边线 |
| 👨‍👩‍👦 东北一家人 | 走完堂屋线，警觉≤20 |
| 🧑‍🍳 金牌帮工 | 走完厨房线+猪圈线，好感≥60 |
| 📱 带货新星 | 走完大集线，第9天选直播，拒绝贴牌粉条 |
| 💥 翻车（彩蛋） | 第6天接下木薯粉条单，第12天强制触发 |
| 🤝 好友 | 好感≥50 |
| 😶 路人 | 兜底结局 |
| 🪿 大鹅之主（隐藏） | 鹅王之证≥3 |
| 😡 被赶走 | 警觉≥45 任意时刻强制触发 |

## 💻 技术实现

### 文件结构

```
src/
├── components/
│   ├── YujieGame.jsx          # 游戏 UI 组件（开始/游玩/结局三阶段）
│   └── YujieGame.css          # 游戏样式
├── data/
│   ├── yujieGameData.js       # 角色/场景/物品/支线/结局/常量
│   ├── yujieGameEvents.js     # 全部剧情事件（约40个节点）
│   └── yujieGameEngine.js     # 纯逻辑引擎（效果结算/条件判定/日期路由）
└── pages/
    └── GameHub.jsx            # 游戏中心入口

test/
├── yujieGameData.test.js      # 数据完整性校验
└── yujieGameFlow.test.js      # 流程仿真（九结局可达性、随机不死局）

public/images/yujie/           # 真实照片素材
```

### 事件数据模型

```javascript
{
  id: 'route_riverside_2',
  title: '心意',
  scene: 'riverside',          // 场景id（背景）
  cg: 'yujie/xxx.jpg',         // 可选，大图覆盖背景
  narration: '旁白……',        // 折叠为对话第一行
  dialogue: [{ character: 'yujie', text: '……' }],
  choices: [{
    id: 'riv_2_1',
    text: '献上野花',
    condition: { hasItem: 'flower' },              // 条件，不满足则隐藏
    effects: { affection: 15, laokuaiAlert: 12, removeItem: 'flower' },
    advanceRoute: 'riverside',                     // 推进支线一幕
    next: 'HUB'                                    // HUB回地图 / NIGHT入夜 / 事件id / 结局id
  }]
}
```

- **effects**：`affection / laokuaiAlert / money / ap / addItem / removeItem / setFlag / goose`
- **condition**：`minAffection / maxAffection / minAlert / maxAlert / hasItem / minMoney / flag / notFlag / flagsAll / minGooseCount / routeCompleted / routesCompleted`

### 游戏状态

```javascript
{
  affection, laokuaiAlert, money, day, actionPoints,
  items: [],                        // 物品id
  routes: { kitchen: 0..3, ... },   // 各支线进度
  flags: {},                        // 剧情开关（noodleDeal/livePath/brother等）
  gooseCount                        // 鹅王之证
}
```

### 结局图鉴

localStorage 键 `yujie_gallery_v2`，开始界面展示收集进度 x/9。

## 🎨 图片素材

- `public/images/yujie/yujie.jpg`、`laokuai.jpg`：角色立绘/头像
- `scene_*.jpg`：场景背景；`cg_*.jpg`：剧情大图；`ending_*.jpg`、`cover.jpg`：结局与封面
- 照片为公开新闻图，粉丝二创娱乐用途；缺失图片由场景渐变自动兜底，不影响游玩
- 杰克/佩斯/翠花/大宝贝/大鹅无真人照片，使用 emoji 立绘

## 🧪 测试
