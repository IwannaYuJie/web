# 《雨姐的心动时刻》重制版 · 游戏开发文档 💕

## 📖 游戏简介

《雨姐的心动时刻》v2.3（当前实现 / 验收版）是一款以东北网红雨姐为原型的恋爱模拟 + 玩梗收集游戏（Galgame）。玩家扮演来到东北农家乐的外国小伙杰克，在 **13 天**旅程中分配行动点（AP）、探索六条支线、经历序章与四个正篇阶段的剧情变迁，最终触发九个结局之一。

本版本在视觉与调度重构的基础上，全面深化了盛宴日（D12）的支线回响网络，新增 5 条专属回响支脉与通用兜底短事件；完善了 D6 粉条商人关键剧情桥接；优化了猪圈与 HUB 状态显示；为多选项引入双列高密度自适应布局；并支持游戏独立直达路由与分享链接。

---

## 🌐 路由与独立分享入口

为了满足将雨姐游戏作为独立入口进行分享与直接访问的需求，前端路由与游戏中心容器架构如下：

### 1. 路由配置与映射
- **游戏中心主路由**：`/games`，展示所有小游戏列表。
- **雨姐独立直达路由**：`/games/yujie`，映射为 `<GameHub initialGameId="yujie-game" />`。
- **独立分享地址**：
  - 正式环境独立分享链接：`https://jumaomaomaoju.cn/games/yujie`
  - 本地开发独立直达链接：`http://localhost:5173/games/yujie`

### 2. 调度与回退行为
- **直达与刷新**：直接打开或刷新 `/games/yujie` 会直接激活雨姐游戏（`YujieGame`），无需先经过游戏中心列表。
- **游戏中心跳转**：在 `/games` 页面点击“雨姐的心动时刻”卡片会导航到 `/games/yujie`，浏览器地址栏保持与当前游戏同步，便于直接复制分享。
- **退出与返回**：雨姐游戏画面使用全屏 Portal 呈现，玩家使用雨姐游戏画面左上角可见的“← 返回游戏列表”按钮回到 `/games` 游戏中心主列表。
- **安全回退**：`GameHub` 组件通过 `initialGameId` 属性判断初始展示游戏，只接受已激活的游戏 ID；非法或未激活的 ID 将安全回退到游戏列表。
- **其他游戏兼容**：其他小游戏仍维持原有的游戏中心内状态切换机制，不新增独立路由。

## 🎮 游戏结构与阶段节奏

游戏全长 13 天，划分为序章 + 四个正篇阶段（`acts` 共 5 段）：

```
第1天：序章（初来乍到，结识大院众人，线性教学）
  ↓
第2-5天：融入大院（熟悉农家日常，与雨姐和伙伴建立初步羁绊）
  ↓ （第3天早晨：大鹅突袭免费固定事件）
第6-8天：选择方向（赶集风波与考验，明确心愿奔赴方向）
  ↓ （第6天早晨：村口大集与粉条商人固定事件）
第9-11天：最后冲刺（大宴筹备，冲刺核心好感、技能与前置条件）
  ↓ （第9天早晨：雨姐的烦恼固定事件）
第12-13天：盛宴与告别（全村盛宴与最终抉择，落幕）
  ↓ （第12天特别日程：杀猪菜大宴专属回响 / 翻车曝光；第13天：离别抉择）
```

### 核心数值

| 数值 | 说明 |
|---|---|
| ❤️ 好感度 (`affection`) | 雨姐对杰克的心意，决定感情类结局 |
| 👀 警觉度 (`laokuaiAlert`) | 老蒯的提防，**≥45 任意时刻强制触发「被赶走」结局** |
| 💰 金钱 (`money`) | 初始 100 元，大厨房打工赚取，村口大集购物消费 |
| 🎒 物品 (`items`) | 送礼或解锁特殊选项（AD钙奶、软枣、酸菜、野花、半扇猪肉、榛蘑、军大衣、大鹅蛋共 8 种） |
| 🪿 鹅王之证 (`gooseCount`) | 与大鹅互动/单挑/摸蛋次数，≥3 解锁隐藏结局 |
| ⚡ 行动点 (`actionPoints`) | 常规自由行动每天 2 点 AP，进入支线地点消耗 1 点 |

## 🧭 心愿导航机制（Wish Guides）

自由行动阶段提供 **6 种可随时切换的心愿指引**（数据定义在 `wishGuides`）：

| 心愿 ID | 目标结局 | 核心推荐路线 | 追踪指标 |
|---|---|---|---|
| `love` | 心动结局 (`ending_love`) | 小河边、堂屋热炕、后山 | 雨姐好感 (≥90)、老蒯警觉 (≤40)、小河边支线 (3幕) |
| `family` | 东北一家人 (`ending_family`) | 堂屋热炕、村口大集 | 堂屋支线 (3幕)、老蒯警觉 (≤20) |
| `chef` | 金牌帮工 (`ending_chef`) | 大厨房、猪圈 | 厨房支线 (3幕)、猪圈支线 (3幕)、雨姐好感 (≥60) |
| `streamer` | 带货新星 (`ending_streamer`) | 村口大集 | 大集支线 (3幕)、选择直播路线、拒绝贴牌粉条 |
| `goose` | 大鹅之主 (`ending_goose`) | 后山、猪圈 | 大鹅互动次数 (≥3) |
| `casual` | 随性农家时光 (`ending_friend`) | 无特定路线推荐 | 纯净体验农家乐，无强制指标 |

**心愿指引设计原则**：
- **纯粹引导，不绑判定**：心愿仅用于在 HUB 界面展示进度清单、高亮推荐路线与下一步建议，**完全不参与**最终结局分支的硬性计算。
- **里程碑提示**：当推荐支线达到第 3 幕上限时，地图卡片自动切换为“已达上限 / 里程碑达成”提示，引导玩家转向其他前置或自由探索。
- **随时切换与容错**：玩家在自由行动 HUB 可随时切换心愿；存档顶层增加可选字段 `wishId`（缺失或非法值自动回退为 `null`，兼容旧存档）。

## 📅 日程调度与关键事件网络

全流程固定日程、AP 结算语义与关键剧情分支网如下：

```
D1 序章 ───> D2-D5 自由行动 (D3早晨: 大鹅突袭, 结算后留 2 AP)
                 │
D6 晨间: 村口大集 ───> 粉条商人事件 (ev_noodle_man)
                 ├─ [接单: 贴牌纯红薯/100元定金/直播担保] ──> 设置 flag: noodleDeal, money+100, ap-1 ──> D12 翻车结局 (ending_noodle)
                 └─ [拒绝: 坚守品质底线] ───────────────────> 设置 flag: refusedNoodles, affection+5, ap-1 ──> 正常盛宴
                 │
D9 晨间: 雨姐的烦恼 (ev_yujie_trouble) ──> 消耗 1 AP，留 1 AP 自由行动
                 │
D12 盛宴日 (全天特别日程 specialSchedule: true，不显示误导 AP)
   ├─ [翻车曝光] (ev_expose) ──> ending_noodle
   └─ [杀猪菜大宴] (ev_feast)
         ├─ 金牌大厨回响 (ev_feast_chef: kitchen+pigpen各3幕) ──────────────┐
         ├─ 直播助阵回响 (ev_feast_streamer: market3幕+livePath+refusedNoodles) ──┤
         ├─ 心动耳语回响 (ev_feast_love: riverside3幕+affection>=75+laokuaiAlert<=40) ┼─> 汇入盛宴落幕 (ev_feast_end) ─> NIGHT ─> D13
         ├─ 炕头敬酒回响 (ev_feast_family: laokuai3幕+laokuaiAlert<=20) ────┤
         ├─ 鹅王巡礼回响 (ev_feast_goose: gooseCount>=3) ───────────────────┤
         └─ 埋头吃肉回响 (ev_feast_generic: 无条件兜底) ─────────────────────┘
                 │
D13 离别抉择 (ev_final) ──> 满足条件选项同时亮起，由玩家主动选择
```

### 1. D6 粉条商人桥接（`ev_noodle_man`）
- **剧情设定**：外地商人上门推销低价木薯粉条，要求贴上“雨姐严选·纯红薯粉条”标签，提供 100 元定金并要求在直播中做信誉担保。
- **分支后果**：
  - **接下定金**：结算 `money +100, ap -1`，写入 `flags.noodleDeal = true`。后续 D12 盛宴直接被工商质检打假曝光事件（`ev_expose`）取代，强制触发 `ending_noodle`（翻车结局）。
  - **断然拒绝**：结算 `affection +5, ap -1`，写入 `flags.refusedNoodles = true`，维持正品口碑，保留后续进入正常盛宴与全部常规结局的资格。

### 2. D12 盛宴专属回响系统
第 12 天杀猪菜大宴（`ev_feast`）提供 **5 条高光专属回响 + 1 条通用兜底**。六个回响均为条件可见选项；当玩家满足多个前置条件时，符合条件的选项会**同时呈现**，由玩家自主选择进入其一：
- **`ev_feast_chef`（掌勺大厨）**：条件为完成大厨房与猪圈各 3 幕（`routes.kitchen >= 3 && routes.pigpen >= 3`）；雨姐当众夸赞杰克刀工掌勺，结算 `affection +6, money +30`。
- **`ev_feast_streamer`（带货新星）**：条件为完成大集 3 幕、第9天选择直播路线且拒绝贴牌粉条（`routes.market >= 3 && flags.livePath && flags.refusedNoodles`）；架起手机进行大宴助农直播，结算 `affection +5, money +20`。
- **`ev_feast_love`（心动回响）**：条件为完成小河边 3 幕、好感度 ≥ 75 且老蒯警觉度 ≤ 40（`routes.riverside >= 3 && affection >= 75 && laokuaiAlert <= 40`）；与雨姐在柴火垛旁互诉心意，结算 `affection +8`，**老蒯警觉度保持不变**（保障 D13 心动结局资格）。
- **`ev_feast_family`（炕头把酒）**：条件为完成堂屋 3 幕且老蒯警觉度 ≤ 20（`routes.laokuai >= 3 && laokuaiAlert <= 20`）；老蒯拉着杰克在热炕头上碰碗称兄道弟，结算 `laokuaiAlert -5, affection +4`。
- **`ev_feast_goose`（鹅王降临）**：条件为大鹅互动次数 ≥ 3（`gooseCount >= 3`）；村里大鹅列队巡游，结算 `affection +5, gooseCount +1`。
- **`ev_feast_generic`（大口吃肉）**：无任何前置条件；通用的丰收聚餐体验，结算 `affection +4`。
- **统一汇聚**：上述 6 个独立分支全部汇入盛宴落幕（`ev_feast_end`），随后进入夜间结算（NIGHT），平滑过渡至 D13 终章。

## 💻 数据模型与纯逻辑引擎

### 纯逻辑引擎接口清单（`yujieGameEngine.js`）

| 函数 | 职责 |
|---|---|
| `initialStats()` | 生成初始玩家状态（初始金钱 100，6 支线进度 0，鹅王计数 0） |
| `applyEffects(stats, choice)` | 不可变结算选项数值、物品增删、AP增减、flag与支线进度推进 |
| `checkCondition(condition, stats)` | 评估选项前置条件（好感/警觉/金钱/物品/flag/鹅王计数/支线幕数） |
| `summarizeChoice(choice)` | 生成选项反馈飘字提示数组（Toast） |
| `morningEventForDay(day, flags)` | 判定当天清晨是否强制触发固定日期事件（D3大鹅、D6赶集、D9烦恼） |
| `routeEventId(routeId, stage)` | 依据支线进度计算对应事件 ID |
| `getActForDay(day)` | 依据天数获取所属的剧情阶段对象 |
| `getNextScheduledEvent(day)` | 获取晚于当前天的下一个固定日程及倒计时 |
| `getWishProgress(wishId, stats)` | 评估当前心愿各项指标达成度（已完成/目标值） |
| `getRecommendedRoutes(wishId)` | 获取当前心愿推荐前往的地点 ID 列表 |
| `shouldRenderStage(event)` | 判定是否需要渲染舞台全身立绘（CG与特定场景安全隐藏） |
| `pickStageSprite(char, seed, pose, expression)` | 舞台立绘按动作/表情/种子层级选图 |
| `pickPortrait(char, seed, expression, kind)` | 头像与立绘哈希保底选图 |

### 边界保护与回归规则
- **老蒯警觉阈值保护**：心动线玩家在 D12 触发心动回响（`ev_feast_love`）时，警觉度不被额外增加，确保在警觉临界值（如 `laokuaiAlert = 40`）下依然稳定保有 D13 心动结局资格。
- **锁定提示与条件容错**：未满足前置条件的选项若定义了 `lockedHint` 则置灰显示提示；未定义则安全隐藏。
- **安全回退机制**：缺失场景图回退至 `yard`；非法人物头像回退至默认种子立绘；损坏存档安全重置。

## 💾 存档与图鉴管理

- **活跃存档键**：`yujie_save_v2`（保存在 `localStorage`）。
- **图鉴收集键**：`yujie_gallery_v2`（记录已解锁结局 ID 数组，支持开始界面 `x/9` 展示）。
- **存档结构示例**：
  ```javascript
  {
    stats: {
      day: 1,
      actionPoints: 0,
      affection: 0,
      laokuaiAlert: 0,
      money: 100,
      items: [],
      routes: { kitchen: 0, pigpen: 0, market: 0, riverside: 0, laokuai: 0, mountain: 0 },
      flags: {},
      gooseCount: 0
    },
    mode: 'event',                  // 'event' | 'hub'
    currentEventId: 'pro_arrive',
    dialogueIndex: 0,
    wishId: null,                   // 当前选中心愿（可选字符串，缺失或非法安全回退 null）
    timestamp: 1711234567890
  }
  ```
