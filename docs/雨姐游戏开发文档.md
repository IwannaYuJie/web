# 《雨姐的心动时刻》v2.4 开发文档 💕

## 📖 架构与系统定位

《雨姐的心动时刻》（v2.4 本地完成待发布版）是一款以东北农家乐为背景的叙事经营与情感羁绊文字单页游戏（SPA）。玩家扮演青年“杰克”，在 13 天的农家乐生活中分配行动力（AP），探索六大地点路线，与雨姐、老蒯、佩斯、翠花以及村霸大鹅展开多元故事，最终通向 14 种不同结局。

v2.4 在 v2.3 的基础上完成了全量演进：
1. **去显式功利迷雾**：选项不再标注 `[+5好感]` 等剧透标签，依赖剧情语境与即时叙事反馈（feedback）；首周目 HUD 仅显示抽象关系阶段词，二周目解锁旅途手记的精确数值与增减记录。
2. **严谨行动力预算（真实 18 AP）**：全流程 13 天自由行动点严格锁定为 18 AP，D6/D9 主线固定各占 1 AP，D12/D13 为专场无自由 AP。
3. **性格与边界深化**：雨姐具备三种人格态（柔软依恋 / 平衡搭档 / 强势主导）；老蒯支持 5 幕深度分支，将“兄弟知己”与“成年双向浪漫”清晰拆分；引入双重欺瞒（`doublePromise`）修罗场机制与粉条危机可补救链条。
4. **数据与视觉资产全量闭环**：事件节点由 42 个扩展至 62 个，对话扩充至 145 句，选项扩充至 147 项（负面/混合/风险选择 52 个，占比 35.37%），结局扩充至 14 个；20 个新增事件与 5 个新增结局全部配备专属 16:9 独立 CG/结局图（共 25 张独立 PNG），且在渲染 CG 场景时隐藏前景立绘。

## 🎮 状态模型与数据契约

### 1. 运行时状态（Stats）

`initialStats()` 完整包含 14 个顶层字段：

| 字段名 | 类型 | 取值范围 | 初始值 | 语义与核心逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| `affection` | number | `0 .. 120` | `0` | 雨姐对杰克的综合好感信赖度，有增有减。 |
| `yujieSoftness` | number | `-40 .. 40` | `0` | 雨姐性格倾向：`> 10` 柔软依恋，`[-10, 10]` 平衡搭档，`< -10` 强势主导。 |
| `laokuaiBond` | number | `0 .. 100` | `0` | 老蒯对杰克的知己兄弟义气。 |
| `laokuaiRomance` | number | `0 .. 100` | `0` | 老蒯与杰克之间的微妙浪漫情愫。 |
| `laokuaiAlert` | number | `0 .. 100` | `0` | 老蒯的戒备排斥度。**任意时点达到 45 立即触发 `ending_kicked`**。 |
| `integrity` | number | `-30 .. 30` | `0` | 杰克的行事诚信与品控底线，影响危机化解与特殊判定。 |
| `money` | number | `0 .. 9999` | `100` | 经营流动资金（元）。 |
| `gooseCount` | number | `0 .. 10` | `0` | 与村霸大鹅交锋/互动累计成功次数（非大鹅只数）。 |
| `actionPoints` | number | `0 .. 2` | `0` | 当日剩余自由行动点数。 |
| `day` | number | `1 .. 13` | `1` | 当前自然日。 |
| `routes` | object | `{ kitchen, pigpen, market, riverside, laokuai, mountain }` | 全 0 | 六大地点已完成幕数记录。 |
| `flags` | object | 键值对 | `{}` | 剧情标记字典。 |
| `items` | Array | 字符串数组 | `[]` | 携带道具列表（AD钙奶、酸菜、军大衣等）。 |
| `historyLog` | Array | 对象数组 | `[]` | 历史选择与即时 feedback 记录（二周目手记数据源）。 |

### 2. 核心剧情 Flags

| Flag 名称 | 类型 | 触发节点与含义 |
| :--- | :--- | :--- |
| `promiseYujie` | boolean | D8 或 D11 做出留在大院陪伴雨姐的排他承诺。 |
| `promiseLaokuai` | boolean | 老蒯第 4 幕或第 5 幕做出相守一生的专属承诺。 |
| `honestBoundary` | boolean | 老蒯第 4 幕明确知己兄弟界限，清理老蒯承诺并防范修罗场。 |
| `mutualLaokuaiConsent` | boolean | 老蒯第 4 幕成年清醒双向确认浪漫标记。 |
| `doublePromise` | boolean | 同时持有 `promiseYujie` 与 `promiseLaokuai` 触发，D12 必入修罗场。 |
| `livePath` | boolean | D9 选定手机直播助农路线。 |
| `noodleCheap` | boolean | D6 购入低价存疑粉条；若未补救 D12 翻车。 |
| `refusedNoodles` | boolean | D6 拒绝低价粉条或斥资采购正品。 |
| `noodleRemedied` | boolean | D8 或 D10 集市化解粉条危机，成功替换正品。 |
| `cuihuaHelp` | boolean | 触发翠花集市插曲，获特制调料与声援。 |
| `gooseAlly` | boolean | 后山收服大鹅结为盟友。 |
| `warningSeen` | boolean | 记录老蒯警戒警告插曲已触发，防重复弹出。 |
| `yujieConfessSeen` | boolean | 记录 D11 雨姐月下深谈插曲已触发。 |

## ⚙️ 纯逻辑引擎接口（`yujieGameEngine.js`）

| 函数名 | 输入参数 | 核心职责与返回值 |
| :--- | :--- | :--- |
| `initialStats()` | 无 | 返回初始 stats 对象（完整包含 14 个顶层字段：8 个数值属性、`actionPoints`、`day`、`routes`、`flags`、`items`、`historyLog`）。 |
| `migrateStats(oldStats)` | `oldStats: object` | 安全升级旧版或损坏存档，保留/深拷贝原 `flags`，补齐顶层数值默认值、`routes`、`items` 与 `historyLog` 并将数值 clamp 在合法区间内。 |
| `resolveChoiceOutcome(choice, stats)` | `choice, stats` | 动态评估 options.outcomes 条件或直接返回 choice，输出当前唯一生效的分支结果。 |
| `applyEffects(stats, choiceOutcome)` | `stats, outcome` | 不可变结算属性、金钱、AP、道具、flags（含 setFlags/clearFlags）及 routes。 |
| `buildHistoryEntry(day, resolvedChoice)` | `day: number, resolvedChoice: object` | 构造历史手记条目对象，记录 `day`、`choiceId`、`text`、`feedback` 与 `effects`。 |
| `getRouteMaxStage(routeId)` | `routeId: string` | 返回地点最大幕数（`laokuai: 5`，`kitchen: 3` 且可重复，其余均为 3）。 |
| `getRouteLockHint(routeId, stage, stats)` | `routeId, stage, stats` | 判断路线是否因天数门槛（如老蒯4需D7+、老蒯5需D10+）或已达上限而锁定并提供提示。 |
| `getSpecialRouteEvent(routeId, stats)` | `routeId, stats` | 仅负责评估并返回特殊插曲事件 ID（`ev_remedy_check`、`ev_cuihua_market`、`ev_peisi_help`、`ev_goose_deep`、`ev_repair_laokuai`、`ev_river_night`）。进入特殊支线时由 UI 预扣 1 AP；普通路线则由首个选项的 `choice.effects.ap = -1` 结算扣除。 |
| `shouldInsertWarning(stats)` | `stats` | 检查 `laokuaiAlert in [30, 44]` 且 `!warningSeen`，决定是否插入免费警告事件 `ev_warning`。 |
| `morningEventForDay(day, flags)` | `day, flags` | 判定晨间主线/回响事件（D3大鹅、D5/D8/D10雨姐回响、D6大集、D9烦恼）。 |
| `nightEventForStats(stats)` | `stats` | 判定晚间特殊事件（如 D11 雨姐深谈 `ev_yujie_confess`）或常规休息。 |
| `getRelationshipStages(stats)` | `stats` | 输出雨姐与老蒯的一周目模糊阶段称号（如“生死搭档”、“过命兄弟”等）。 |
| `checkCondition(condition, stats)` | `condition, stats` | 纯可序列化前置条件判定（支持 min/max、flags、items、routes 等维度）。 |
| `shouldRenderStage(event)` | `event` | 判定是否渲染前景立绘（CG 事件或明确声明隐藏立绘时返回 false，防止立绘叠在 CG 上）。 |

## 🗺️ 18 AP 真实行动力与关键调度表

全流程自由行动点分配：
- **D1**：序章（0 AP）
- **D2 - D5**：每日 2 AP（共 8 AP）
- **D6**：大集主线固定消耗 1 AP，剩余 **1 AP**
- **D7 - D8**：每日 2 AP（共 4 AP）
- **D9**：烦恼主线固定消耗 1 AP，剩余 **1 AP**
- **D10 - D11**：每日 2 AP（共 4 AP）
- **D12**：杀猪大宴全天专场（0 AP）
- **D13**：终章抉择（0 AP）
- **总计自由 AP**：`8 + 1 + 4 + 1 + 4 = 18 AP`。

### 62 节点与 14 结局对应分布

```
[D1 序章: pro_arrive ~ pro_meet_yujie] (0 AP)
  ↓
[D2-D5 自由行动: 6 地点] (8 AP)
  ├─ D3 晨间: 大鹅突袭 ev_goose_attack (免费, 留 2 AP)
  └─ D5 晨间: 雨姐初显回响 ev_echo_d5 (免费, 留 2 AP)
  ↓
[D6 村口大集: ev_market_day -> ev_noodle_man] (消耗 1 AP, 留 1 AP)
  ├─ 选贪便宜: noodleCheap=true, noodleDeal=true
  ├─ 选验货/拒采: refusedNoodles=true
  └─ 选斥资买正品: refusedNoodles=true, integrity+12
  ↓
[D7-D8 自由行动] (4 AP)
  ├─ D7: 老蒯第 4 幕解锁 (坦白知己 vs 浪漫确认)
  └─ D8 晨间: 雨姐烦恼回响 ev_echo_d8 (免费, 留 2 AP)；若有 noodleCheap 可在集市补救 ev_remedy_check
  ↓
[D9 雨姐的烦恼: ev_yujie_trouble] (消耗 1 AP, 留 1 AP)
  ├─ 选直播带货: livePath=true
  └─ 选大锅菜/陪伴: 强化属性
  ↓
[D10-D11 自由行动] (4 AP)
  ├─ D10 晨间: 盛宴筹备回响 ev_echo_d10 (免费)；老蒯第 5 幕解锁 (红木木雕)

  ↓

  ├─ [修罗场判定] 若 doublePromise === true -> ev_shura_reveal -> ev_ending_shura -> ending_shura
  ├─ [翻车判定] 若 noodleCheap 且未补救 -> ev_expose -> ending_noodle

  ├─ ending_love / ending_love_soft / ending_love_power (雨姐三态爱情)

  ├─ ending_family (东北一家人) / ending_chef / ending_streamer / ending_goose / ending_friend / ending_bye
```
